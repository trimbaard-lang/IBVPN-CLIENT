# IB VPN Client — officiële updates

Dit is het openbare distributiekanaal voor **IB VPN Client** van **INBUSINESS ICT**.

De applicatie biedt een gebruiksvriendelijke Windows-client voor WireGuard VPN, met beveiligd profielbeheer, verbindingsdiagnose en updatebeheer.

## Downloads en updates

Nieuwe, geteste versies worden gepubliceerd onder **[Releases](https://github.com/trimbaard-lang/IBVPN-CLIENT/releases)**.

De VPN-client kan controleren of er een nieuwere stabiele release beschikbaar is. Beschikbare updates worden alleen met toestemming gedownload en geïnstalleerd.

> Er is niet automatisch een update beschikbaar zodra een nieuwe versie wordt gebouwd. Een release moet eerst expliciet worden getest en gepubliceerd.

## Voor beheerders

- Publiceer uitsluitend **generieke release-installers** vanuit de IB VPN Branding Builder.
- Publiceer geen klantgebonden installers, VPN-configuraties, sleutels, klantlogo's, supportpakketten of andere vertrouwelijke gegevens.
- Voeg bij iedere release de door de Branding Builder gegenereerde SHA-256-controleinformatie en release notes toe.
- Controleer de installer vóór publicatie op een Windows-testcomputer.
- Installeer updates niet terwijl een VPN-verbinding actief is.

## Klantbranding

De client bewaart klantnaam, logo, VPN-profielen en instellingen buiten de vervangbare programmabestanden. Daardoor kan een generieke update de bestaande instellingen behouden. Oude installaties moeten mogelijk eenmalig worden gemigreerd met een klantgebonden installer.

## Ondersteuning

Neem voor ondersteuning contact op met **INBUSINESS ICT** via de gebruikelijke servicedeskkanalen.
